# Cursor: core loading

Use [the shared setup](../../docs/setup.md) for copying, merging, updates, and removal.

Cursor supports `AGENTS.md` in the project root and subdirectories. More specific
instructions are combined with parent guidance. Add the core to the project entry;
avoid copying the same guidance into an always-on `.cursor/rules/*.mdc` as well.

Keep native scoped rules for actual project-specific conventions. Inspect active
rules in the destination project and start a fresh Agent session after changes.
Describe the task directly; installed Skills and planning remain native features.

Status: official documentation checked on 2026-10-13; native loading and behavior
have not been tested by AIBoot. This guide covers local Agent guidance, not every
editor feature, multi-tool coexistence, or remote/cloud behavior.

Source: [Cursor Rules and AGENTS.md](https://cursor.com/docs/rules).
